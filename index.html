Cài đặt nguồn dữ liệu
Lưu trong trình duyệt — không cần nhập lại lần sau.
Hướng dẫn lấy API Key:
1. Vào Google Cloud Console → Bật Google Sheets API
2. Vào APIs & Services → Credentials → + Create Credentials → API Key
3. Copy Sheet ID từ URL Google Sheet của bạn (đoạn dài giữa /d/ và /edit)
4. Mở Google Sheet → Share → Anyone with the link → Viewer
